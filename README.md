# Batumi Buses — финальная версия

## Публикация на GitHub Pages

Загрузите **содержимое этого архива** непосредственно в корень репозитория. В корне должны находиться:

- `index.html`
- `manifest.json`
- `sw.js`
- папка `assets`

GitHub Pages:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

## Обновление и кэш

Финальный Service Worker использует безопасную схему:

- страницы и переходы — сначала интернет, затем офлайн-копия;
- CSS, JavaScript и PNG — локальный кэш с автоматическим обновлением;
- старые версии кэша удаляются при активации;
- новая версия Service Worker активируется автоматически;
- локальные CSS и JS подключены с версией, чтобы браузер не сохранял устаревшие файлы.

Обе ссылки должны открывать одну и ту же актуальную версию:

- `/Batumi-Buses-v2/`
- `/Batumi-Buses-v2/index.html`
